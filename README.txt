말하는 가계부

핵심 기능
- 한국어 음성 입력: 날짜, 금액, 수입/지출, 분류, 결제수단 자동 추정
- 말로 조회: 예) "이번 달 식비 얼마야", "오늘 지출 얼마야"
- 영수증 카메라 촬영 / 갤러리 불러오기
- 영수증 OCR: Tesseract.js를 이용해 날짜, 금액, 상호 자동 추정
- 저장 전 확인 화면
- 월 수입/지출/잔액 요약
- IndexedDB 로컬 저장(영수증 사진 포함)
- CSV 내보내기, JSON 전체 백업/복원

사용 팁
1) Android Chrome에서 사용 권장
2) 음성 입력 예: "오늘 점심 9천원 카드", "어제 주유 7만원", "오늘 월급 350만원 들어왔어"
3) 영수증 OCR은 인터넷 연결이 필요하며 인식 오류가 있을 수 있으므로 저장 전 금액 확인 권장
4) 앱 데이터는 서버가 아니라 해당 브라우저에 저장됨

배포
- 폴더의 파일 전체를 GitHub Pages 또는 Vercel에 그대로 올리면 됩니다.
- index.html이 시작 파일입니다.
- 고정 주소 업데이트를 중요하게 생각해 서비스워커 캐시를 넣지 않았습니다.


[월별 관리 업데이트]
- 중앙 DB 없음: 모든 가계부 데이터는 각 사용자 휴대폰 브라우저 IndexedDB에 저장됩니다.
- 월별 지출/수입/잔액/건수/하루평균, 최근 6개월 지출 비교, 카테고리별 지출 비율을 제공합니다.
- 같은 주소에 파일을 덮어쓰면 version.json 확인을 통해 새 앱 파일을 다시 불러오도록 구성했습니다.
- 앱 업데이트는 IndexedDB의 가계부 기록을 삭제하지 않습니다.


[입력 개선]
- 화면 하단에 지출 입력 / 말하기 / 수입 입력을 항상 표시합니다.
- 수입 입력은 급여, 용돈, 환급, 이자, 기타수입으로 바로 기록할 수 있습니다.
- 개인 기록은 기존 IndexedDB에 그대로 저장되므로 앱 파일 업데이트와 분리됩니다.
